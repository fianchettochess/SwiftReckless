# Security Policy

## Supported versions

Security fixes target the latest tagged release and the `main` branch. Older
releases may not receive patches.

## Reporting a vulnerability

Please do not publish exploit details, credentials, private paths, or sensitive
logs in an issue or pull request. Use GitHub's private vulnerability reporting
form in this repository's **Security** tab. If that form is unavailable,
contact a maintainer through GitHub without including sensitive details so a
private reporting channel can be arranged.

Reports involving unsafe FFI behavior, malformed UCI input, engine crashes or
hangs, excessive resource use, NNUE download or verification, archive
provenance, or concurrent lifecycle handling are especially useful. Include
the affected version, platform, a minimal reproducer, impact, and any suggested
mitigation when possible. Non-sensitive defects can use the public issue
tracker.
